# CarePulse Vibe Coding Rules
- Primary Theme Base: #E6E9E6 (Use as main app background)
- Accent Highlight: #8BD843 (Primary buttons, active states)
- Secondary Accent: #619930 (Borders, hover states)
- Text/Dark Base: #000000
- Framework: Next.js App Router (TypeScript)
- Database: Supabase PostgreSQL
- Components: Tailwind CSS with shadcn/ui patterns
